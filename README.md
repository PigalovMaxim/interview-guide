# Interview Guide

Редакция 5: 540 материалов для фронтенд-интервью — 480 технических вопросов и 60 практических задач. В каждой из девяти тем на каждой из четырёх вкладок по 15 карточек.

**Сайт:** https://pigalovmaxim.github.io/interview-guide/

## Локальный запуск

Откройте `web/index.html` в современном браузере. Установка зависимостей и сборка не требуются: сайт написан на HTML, CSS и JavaScript, оценки сохраняются в `localStorage` браузера.

В разделе «Итоги» доступны отчёты Word (.docx) и Excel (.xlsx): сводка тем и уровней с поставленными оценками и список оценённых материалов. «Без оценки» исключается, «Не ответил» сохраняется. Экспорт охватывает всё интервью независимо от выбранной темы; счётчики покрытия остаются относительно исходного банка (540 / 135 / 15). Пустое интервью скачивается без строк тем и вопросов. Экспорт выполняется в браузере. Открытие вопроса прокручивает экран к карточке.

У каждой практической задачи рядом с копированием стартового кода есть кнопка «Открыть Codefile». Она открывает [codefile.io](https://codefile.io/) в новой вкладке для совместного редактирования; комнату и перенос кода участники организуют самостоятельно. Код, решения и оценки по ссылке не передаются.

Подробности устройства и поведения сайта — в [web/README.md](web/README.md). Спецификации проекта находятся в `_bmad-output/`.

В банке 19 вопросов из публичной выборки EasyOffer, 77 из подборки YauhenKavalchuk/interview-questions и 384 редакционных технических кейса проекта. Из GitHub-вопросов 38 адаптированы: исходные текст, грейд и permalink хранятся отдельно от редакционной формулировки. Среди редакционных кейсов 13 новых дополнены по официальной документации. [Аудит грейдов и повторов](docs/grade-audit-2026-11-17.md) описывает 51 замену.

На каждой вкладке 135 материалов. Стартовая тема — JavaScript. 429 прежних вопросов и все 60 задач сохраняют ID; 51 заменённый вопрос получил новый ID. Оценки продолжают храниться в `interview-guide.ratings.v3`: сохранённые вопросы восстанавливают оценки, новым не присваиваются оценки удалённых. Архивы прежних редакций и оформление сохраняются.

Проверки: `node --test tests/*.test.js` и `node tests/browser-check.cjs` (внешний Playwright и Chromium/Edge). Снимки источников и редакционные исходники находятся в `data-sources/`; `node data-sources/build-bank.cjs` пересобирает тематический банк, не меняя `coding.js`.

## Публикация

Исходники проекта хранятся в ветке `main`, опубликованная версия сайта — в корне ветки `gh-pages`. Чтобы отправить изменения и обновить сайт, выполните из корня проекта:

```sh
git add web data-sources tests README.md
git commit -m "Update website"
git push origin main
git subtree push --prefix web origin gh-pages
```

В настройках репозитория **Settings → Pages → Source** выбран **Deploy from a branch**, ветка **gh-pages**, каталог **/ (root)**. После обновления ветки GitHub автоматически публикует сайт.
