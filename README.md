# Interview Guide

Редакция 3: 145 материалов для фронтенд-интервью — 45 технических вопросов EasyOffer, 40 отобранных вопросов из YauhenKavalchuk/interview-questions и 60 сохранённых практических задач. Девять тем, четыре вкладки, редакционные ответы, две ветки уточнений, критерии и экран итогов.

**Сайт:** https://pigalovmaxim.github.io/interview-guide/

## Локальный запуск

Откройте `web/index.html` в современном браузере. Установка зависимостей и сборка не требуются: сайт написан на HTML, CSS и JavaScript, оценки сохраняются в `localStorage` браузера.

Подробности устройства и поведения сайта — в [web/README.md](web/README.md). Спецификации проекта находятся в `_bmad-output/`.

Тематические вопросы заменены; все 60 практических задач сохранены с единственной коррекцией решения `calendar-date`: нестроковый ввод теперь сразу возвращает `false`. Все вопросы, ID и остальные поля задач неизменны. EasyOffer предоставил ограниченную публичную выборку по 20 позиций на уровень; после исключения нетехнических вопросов осталось 18 Junior, 14 Middle и 13 Senior. Дополнение GitHub содержит 14 Junior, 14 Middle и 12 Senior из разделов закреплённой версии репозитория. Это подборки, а не полные каталоги. Источник каждого вопроса показан отдельно от редакционного разбора.

TanStack Query и тематические группы «Сложных вопросов» пусты; эта вкладка содержит только 15 сохранённых практических задач. Стартовая тема — JavaScript. Счётчики и итоги учитывают фактическое наполнение. Новое интервью хранится в `interview-guide.ratings.v3`; ключи `interview-guide.ratings` и `.v2` не переносятся и не изменяются даже при очистке. Оформление сохраняется.

Проверки: `node --test tests/*.test.js` и `node tests/browser-check.cjs` (внешний Playwright и Chromium/Edge). Снимки источников и редакционные исходники находятся в `data-sources/`; `node data-sources/build-bank.cjs` пересобирает тематический банк, не меняя `coding.js`.

## Публикация

Исходники проекта хранятся в ветке `main`, опубликованная версия сайта — в корне ветки `gh-pages`. Чтобы отправить изменения и обновить сайт, выполните из корня проекта:

```sh
git add web data-sources tests README.md
git commit -m "Update website"
git push origin main
git subtree push --prefix web origin gh-pages
```

В настройках репозитория **Settings → Pages → Source** выбран **Deploy from a branch**, ветка **gh-pages**, каталог **/ (root)**. После обновления ветки GitHub автоматически публикует сайт.
