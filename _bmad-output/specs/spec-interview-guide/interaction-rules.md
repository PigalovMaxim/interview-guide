# Поведение интерфейса и состояние

Обязательное приложение к [SPEC.md](SPEC.md), CAP-1…CAP-7. Детали A-2 и A-3 — рабочие допущения; они делают поведение определённым без выбора фреймворка и библиотеки стора.

## Навигация и раскрытия

| Ситуация | Поведение |
| --- | --- |
| Первый вход | Активны Junior и HTML; показан список из 15 свёрнутых карточек. Оформление тёмное, если нет сохранённого выбора. Оценки восстанавливаются до разрешения их изменения. |
| Выбор вкладки | Сохраняется выбранная тема, меняется список уровня; оценки остаются прежними. Новый список свёрнут. |
| Выбор темы | Уровень сохраняется; отображаются её 15 материалов. Новый список свёрнут. |
| Раскрытие вопроса | По нажатию заголовка появляются материалы разбора. Можно открыть несколько карточек одновременно. |
| Раскрытие задачи | Сначала видны условие, примеры и стартовый код. Отдельное действие «Показать разбор» раскрывает решение и остальные подсказки интервьюеру. |
| Сворачивание задачи | Закрываются и основная карточка, и вложенный разбор, чтобы следующий просмотр снова начинался с условия. |
| Свёрнутая карточка | Видны порядковый номер, формулировка/название, состояние оценки; в сложной вкладке также целевой уровень. |
| Перезагрузка | Оценки и оформление восстанавливаются; навигация возвращается к Junior/HTML, карточки свёрнуты. |

На странице видны переключатель оформления и кнопка очистки. Конкретное расположение списка тем и адаптивной навигации определяет UX по Q-1; достижимость всех четырёх вкладок и девяти тем обязательна.

## Копирование задачи

| Действие | Точное содержимое буфера |
| --- | --- |
| «Скопировать код» | Только `starterCode`, с исходными переносами и отступами. Без номеров строк, оформления и обрамляющих Markdown-ограждений. |
| «Скопировать задачу» | Название, условие, примеры и стартовый код в читаемом текстовом виде. Код может быть отделён Markdown-ограждением с языком. |

Ни одно действие не копирует `shortAnswer`, `explanation`, `assessment`, `followUps`, `solution`, `edgeCases` или `complexity` из части для интервьюера. Это сохраняется даже при открытом разборе. Копирование не меняет оценки и раскрытие карточки.

Успех показывается только после подтверждённого копирования. При отказе доступно сообщение «Не удалось скопировать. Выделите и скопируйте текст вручную»; исходный текст остаётся доступным для выделения. Длинный код прокручивается внутри блока, а не расширяет всю страницу.

## Оценка

| Значение состояния | Подпись | Значение для интервьюера |
| --- | --- | --- |
| Отсутствует | Без оценки | Вопрос ещё не задавали или не оценили; это не отрицательный ответ. |
| `no_answer` | Не ответил | Интервьюер отметил отсутствие содержательного ответа. |
| `basic` | Базово | Ответ соответствует базовым признакам из карточки. |
| `confident` | Уверенно | Ответ соответствует уверенным признакам из карточки. |
| `deep` | Глубоко | Ответ соответствует глубоким признакам из карточки. |

У каждого ID не более одной оценки. Выбор другого значения заменяет предыдущее; нажатие уже выбранного не добавляет дубль. Оценка ставится явно, не вычисляется по раскрытию или копированию. Результаты разных уровней и тем независимы. Сайт не усредняет отметки в автоматический грейд.

## Логическая модель состояния

| Данные | Область жизни | Правило |
| --- | --- | --- |
| Каталог материалов | Контент приложения | Не изменяется оценками или очисткой; способ поставки — Q-2. |
| `ratingsById` | Стор и локальное сохранение | Карта устойчивых ID в одно из четырёх значений. Только текущее интервью. |
| `schemaVersion` | Локальное сохранение оценок | Позволяет распознать несовместимый формат, не принять его за пустое интервью. |
| `theme` | Настройка пользователя | `dark` или `light`; сохраняется отдельно от результатов интервью. |
| `activeTab`, `activeTopic` | Текущая страница | Не сохраняются между перезагрузками. |
| Раскрытые карточки и разборы | Текущий список | Сбрасываются при смене списка и перезагрузке. |
| Состояния копирования/сохранения | Текущая страница | Не являются оценкой, историей интервью или содержимым банка. |

Нумерация 1–15 не является ключом оценки. Косметическая правка и перестановка карточки сохраняют её ID; замена задания другим получает новый ID. Удалённый ID не присваивается новому вопросу.

Локальное сохранение относится к тому же сайту и браузеру. Перенос на другое устройство, восстановление после очистки данных браузера и согласование одновременно открытых вкладок не обещаются. Базовый сценарий A-3 — одна активная вкладка.

## Восстановление и ошибки

1. При загрузке приложение читает и проверяет сохранённые оценки до первой записи текущего состояния. Пустой стартовый стор не должен затереть найденные результаты.
2. При корректных данных восстанавливаются все оценки известным ID с допустимыми значениями. Отсутствующая запись означает «без оценки».
3. При неизвестных ID или отдельных недопустимых значениях валидные оценки сохраняются, остальные пропускаются с сообщением о неполном восстановлении. Оценка никогда не сопоставляется с другим материалом по позиции.
4. При повреждённой структуре или неизвестной версии формата приложение не падает и не перезаписывает исходные данные автоматически. Сообщает, что результаты не восстановлены; новые оценки работают только в памяти до явной очистки несовместимого сохранения.
5. При недоступном чтении/записи приложение остаётся пригодным для интервью. Поставленные оценки остаются в текущем сторе, но видно сообщение «Оценки сохраняются только до закрытия страницы». При следующей успешной записи сообщение снимается; до неё сохранение не обещается.
6. Сбой настройки оформления не мешает читать вопросы и выставлять оценки; выбранная тема применяется на текущей странице, а её несохранение обозначается отдельно.

## Очистка

- Нажатие «Очистить оценки» открывает подтверждение: «Очистить оценки текущего интервью во всех темах и уровнях?» Действия — «Отмена» и «Очистить».
- Отмена оставляет стор, локальное сохранение и тему прежними.
- Подтверждение очищает только результаты текущего интервью во всех четырёх вкладках и девяти темах. Контент и оформление не затрагиваются; данные других приложений или сайта целиком не удаляются.
- Успешный сброс отражается сразу и сохраняется после перезагрузки. Повторная очистка пустого интервью безопасна и не создаёт новую историю.
- Если удалить сохранённые результаты не удалось, оценки текущей страницы очищаются, но интерфейс сообщает, что старые результаты могут вернуться после перезагрузки. Нельзя показывать безусловное «Очищено» при таком сбое.
- Подтверждение доступно с клавиатуры; при закрытии фокус возвращается к кнопке очистки.

Технический способ записи и формат сериализации определяются при выборе стека. Продуктовый контракт требует указанных состояний, а не конкретного API хранения.
