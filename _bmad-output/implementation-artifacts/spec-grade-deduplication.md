## Intent

В банке повторяются вопросы между грейдами, а некоторые старшие карточки проверяют только основы. Удалить буквальные и смысловые дубли, заменить их вопросами соответствующего уровня из YauhenKavalchuk/interview-questions. Для TanStack Query и пробелов Redux пользователь разрешил дополнение по официальной документации.

## Boundaries & Constraints

Сохранить 15 карточек в каждой из 36 групп, 480 теоретических вопросов и 60 практических задач. Практические задачи, решения и их ID сохранить побайтно. Не затрагивать UI, экспорт, Codefile, фильтрацию оценок и ключ ratings.v3. Неизменённые карточки сохраняют ID, заменённые получают новые ID, чтобы прежняя оценка не стала оценкой другого вопроса. Первичные источники хранить честно: GitHub permalink на исходный вопрос и грейд источника; редакционная адаптация отдельно. Advanced — глубина/ракурс, а не выдуманный грейд источника. Не подменять технические вопросы вопросами про опыт.
