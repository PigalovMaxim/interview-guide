## Intent

Добавить страницу «Итоги» с четырьмя круговыми pie-диаграммами: Junior, Middle, Senior, «Сложные вопросы». Секторы группируют оценённые вопросы по девяти темам; подробности показывают качество ответов каждой темы.

## Boundaries & Constraints

**Always:** Только существующие vanilla HTML/CSS/JS, мягкие светлая/тёмная темы. Размер сектора — число явно оценённых вопросов темы среди оценённых вопросов вкладки. «Не ответил» учитывается как выставленная оценка; отсутствие отметки исключается. Подписи объясняют знаменатель процентов. По теме доступны четыре счётчика отметок и покрытие X/15. Нет вычисляемого грейда или процента знания.

**Never:** Библиотеки диаграмм, фреймворки, npm, сборка, тестовая инфраструктура, изменение банка/ID или формата сохранения, удалённые операции. Ранее пользователь прямо потребовал удалить Vite и тесты; это ограничение действует для текущей работы.

## Implementation Notes

- Нужный результат и продолжение реализации уже авторизованы запросом пользователя; повторного согласования не требуется.
- Решение: отдельный экран по hash `index.html#results`, поскольку file:// localStorage между разными HTML-файлами может быть изолирован. Общий документ сохраняет и временные оценки при отказе хранилища. На возврате сохранять выбранные вопросы и раскрытия.
- Круги полные, без отверстия; SVG средствами браузера. Ноль/одна положительная тема обрабатываются отдельно. Легенда доступна с клавиатуры, выбор также возможен кликом по сектору; числовые детали остаются текстом.
- Отрисовка не должна перехватывать фокус при изменении темы. Учесть reduced motion и existing storage notices. В существующем окружении browser host/native pipe были недоступны; проверить возможность, при недоступности честно ограничить визуальную проверку.
