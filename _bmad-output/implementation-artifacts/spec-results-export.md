## Intent

По прямому поручению пользователя убрать выделенную на первом скриншоте общую памятку о «Уверенно» и «Глубоко», убрать раскрывающийся блок «Контекст и первичные источники», прокручивать к открываемому вопросу и добавить скачивание итогов Word и Excel. Продолжение после прерывания явно разрешено. Остальные пояснения, критерии и происхождение вопросов сохраняются.

## Boundaries & Constraints

Состав банка, его 540 ID и текущий ключ оценок v3 не менять. Удалить отображение контекста и первичных ссылок, сохранив сами проверенные данные. Экспортировать настоящее содержимое DOCX/XLSX в браузере, без сервера, CDN и переименования HTML в Office. В сводке все четыре уровня и 36 групп, четыре оценки и число оценённых/всего; в подробностях только оценённые вопросы. «Не ответил» — оценка, пустая отметка ей не является. Файлы содержат текущий снимок всех оценок независимо от открытого уровня и выбранного сектора. Пустое интервью экспортируется с нулевыми счётчиками, без выдуманных оценок. Данные пользователя и XML корректно экранируются.

## I/O & Edge-Case Matrix

| Сценарий | Результат |
| --- | --- |
| Открытие карточки мышью или клавиатурой | Заголовок оказывается у верхней границы экрана; фокус сохраняется, уменьшение движения учитывается |
| Сворачивание | Нет программной прокрутки |
| Экспорт после оценивания и после очистки | Значения совпадают с текущим состоянием, обновление не нужно |
| Пустое интервью | Валидные файлы, все 36 групп с нулями |
| Спецсимволы и начало текста с `=` | Текст сохранён, формулы не создаются |

## Code Map

- `web/app.js`: `analysis()` рисует памятку и блок ссылок; обработчик disclosure управляет раскрытием и inert.
- `web/results.js`: `aggregate()` и store содержат необходимые исходные данные; новый построитель отчёта и две кнопки скачивания с live status.
- `web/results-export.js`: автономный OOXML ZIP writer и преобразование отчёта в DOCX/XLSX, не зависит от DOM.
- `web/index.html`, `web/styles.css`: кнопки экспортов и их адаптивный вид; отдельный ключ кеша UI без изменения редакции данных.
- `tests/browser-check.cjs`: 36 групп, практика, оценки, мобильный экран; обновить проверки намеренно скрытых полей и добавить реальные downloads/scroll.
- `tests/export.test.js`: проверить ZIP CRC/части, XML, русские строки, числа, полный/пустой отчёт и буквальные формулы.
