# Аудит грейдов и повторов: редакция 5

Проверка охватывает все 540 карточек: 480 теоретических вопросов и 60 практических задач, 36 групп по 15. Базовая редакция — commit `0c7b1ea01db87e2e0e562cb96347b826f22a067b`. Предметные аудиты проверяли основной механизм, действие кандидата и ожидаемое рассуждение, а не только совпадение слов.

Заменена 51 карточка: JavaScript — 19, TypeScript — 5, React — 7, CSS — 3, HTML — 1, архитектура — 3, Redux — 7, TanStack Query — 6. План исходно содержал 50 замен; перекрёстная проверка обнаружила дополнительный дубль `project:tanstack-query:draft-reconcile` / `project:react:draft-conflict`. Query-кейс заменён потоковой передачей pending query при SSR. В manifest каждая строка содержит `retiredId`, конкретную причину и полную новую карточку.

Удалены буквальные повторы вопросов EasyOffer между грейдами и выявленные смысловые повторы: жизненный цикл ресурсов, ключи/идентичность запроса, тестовые границы, преобразования DTO, granular selectors и сохранение draft. При сверке новых кандидатов с оставшимся банком исключены повторные темы `setQueryData(undefined)`, `select` и mutation scope; вместо них выбраны точные коллизии `hashKey`, tracked observer properties и `networkMode`. Новый JavaScript вопрос об атрибутах не повторяет HTML default/live/reset: он проверяет boolean reflection, строковый контракт атрибута и произвольные JS-свойства.

38 замен — русские редакционные адаптации тем из [YauhenKavalchuk/interview-questions, commit 08922e3](https://github.com/YauhenKavalchuk/interview-questions/tree/08922e3529a138e676de51b091dbd5a2e5aa1b90/questions). У каждой сохранены точный исходный текст с Markdown, путь, строка, исходный грейд по ближайшему заголовку и permalink. `source.adapted:true` отделяет новую задачу от исходной цитаты; интерфейс поясняет адаптацию. `grade-upstream-evidence-2026-11-17.json` содержит 38 использованных строк и заголовков, а также SHA-256 десяти полных исходных документов. Полные Markdown были независимо сверены с закреплённым upstream; ошибочная классификация Lead во временном catalog.json не использовалась.

Ещё 13 замен — авторские кейсы Redux/TanStack Query по официальной документации, без приписывания GitHub-происхождения. Две детали реализации закреплены отдельными commit: [RTK Query serializer](https://github.com/reduxjs/redux-toolkit/blob/1a7d3b5251ceda61b77928e357a22086b45aaab1/packages/toolkit/src/query/defaultSerializeQueryArgs.ts) и [TanStack hashKey](https://github.com/TanStack/query/blob/11312f9e979f783d206955f6eb1433b44f80dada/packages/query-core/src/utils.ts). 43 первичные ссылки проверены HTTP GET; дата UTC, статус и хеш фактически полученного документа записаны в `grade-reference-verification-2026-11-17.json`. Доступность HTTP отдельно от предметной проверки; прежние снимки и даты не переписаны.

После замен состав: 19 EasyOffer, 77 GitHub (39 сохранённых и 38 адаптаций), 384 редакционных кейса (371 сохранённый и 13 новых). Сохранённые 429 теоретических карточек, включая их ID, проверяются SHA-256 без `ordinal`; 51 новая карточка получает новый `curated:*` ID. Допустимые пересечения различают механизм и действие: picture/srcset; date-step/number-step; submit/manual validation; cascade layers/revert-layer; covariance/method bivariance; Array.from/iterator и sync generator cleanup. DDD на Senior требует выбора владельцев/границ и эволюции интеграции, а простой пример разных моделей в архитектуре Junior проверяет локальный смысл данных. Это общие предметные области с разными контрактами ответа.

Грейды — редакционные ориентиры, а не сертификация кандидата. Senior задачи требуют сложного механизма либо системного выбора уже в основном вопросе. Advanced означает дополнительную инженерную глубину или нюанс, при честных `source.level` и `targetLevel`; редкий API не объявляется обязательным минимумом общего грейда. Наличие полей и автоматическое отсутствие буквальных повторов не доказывают отсутствие всех возможных смысловых совпадений; этот слой проверен предметно по согласованному плану.

Невалидные замены сохраняют предыдущие файлы. Unit suite проверяет все удаления/замены, неизменность retained карточек, практику, восстановление оценок и экспорт. Browser-check прошёл: 36 × 15, карточки/источники/ветки, копирование и Codefile всех 60 задач, оценки и Word/Excel, мобильная раскладка и file://.
