# Interview Guide

Сайт на обычных HTML, CSS и JavaScript. Откройте `index.html` в современном браузере двойным кликом или через Live Server в VS Code. Установка пакетов и сборка не требуются.

- `index.html` — разметка страницы и подключение скриптов.
- `styles.css` — мягкие светлая и тёмная темы, адаптация и анимации.
- `app.js` — навигация, раскрытия, подсветка и копирование кода.
- `results.js` — экран итогов, группировка оценённых вопросов по вкладкам и темам, SVG-диаграммы.
- `store.js` — небольшой стор на обычном JS с сохранением оценок и оформления в `localStorage`.
- `data/catalog.js` — вкладки и темы; остальные файлы `data/` содержат 540 материалов, включая 60 задач. Файлы подключаются обычными script-тегами, поэтому сайт работает без сервера и загрузки данных через fetch.

Оценки относятся к одному текущему интервью. Кнопка «Очистить оценки» очищает все темы и уровни после подтверждения, сохраняя оформление. Стабильные ID и прежние ключи сохранения сохранены.

Раздел «Итоги» (`index.html#results`) показывает четыре круговые диаграммы: Junior, Middle, Senior и «Сложные вопросы». Размер сектора — число оценённых вопросов темы среди всех оценённых вопросов соответствующей вкладки; «Не ответил» включается, вопросы без отметки исключаются. Легенда содержит все девять тем, число вопросов и их долю. Выбор сектора или кнопки легенды показывает четыре счётчика оценок и покрытие темы X/15. Эти доли не означают процент знания и не определяют грейд. Переходы между вопросами и итогами, в том числе кнопками браузера, сохраняют текущее интервью и раскрытые карточки в одном документе даже при недоступном `localStorage`.

В начале раскрытой карточки находится блок «Спросите кандидата»: один самостоятельный кейс (`question`) и, где нужно, пример (`questionCode`, `questionCodeLanguage`). Короткий `title` остаётся заголовком списка. Ответы и помощь находятся в части для интервьюера; `questionPoints` удалено из контракта.

Сначала дайте кандидату решить основное задание без подсказок. Затем выберите одну из двух веток `followUps`: `{kind: "support", question, expected}` при затруднении или `{kind: "transfer", question, expected}` при уверенном ответе. Задавайте вопросы по одному, дожидаясь рассуждения. `expected` — предметный признак для интервьюера, его не зачитывают кандидату. Поддержка проверяет отдельный шаг; перенос меняет условия и проверяет независимое применение.

«Базово» отмечает частичное понимание. «Уверенно» требует самостоятельного выполнения всего основного задания, включая его ограничения и примеры. «Глубоко» требует также самостоятельного переноса; правильный ответ после подсказки сам по себе этого не доказывает. Критерии `assessment.basic/confident/deep` описывают наблюдаемые признаки, а решения и `shortAnswer` дают возможный путь. Обоснованное альтернативное решение принимается, если выполняет контракт, даже когда использует другой алгоритм.

Рекомендация каждой вкладки хранится в `tabs[].guidance`: Junior — базовый механизм на небольшом примере, Middle — самостоятельное применение и диагностика, Senior — выбор при ограничениях и проверка последствий. «Сложные вопросы» добавляют глубину относительно `targetLevel`. Выбирайте темы под роль и контекст; знание всех библиотек, редких API и алгоритмов не является обязательным минимумом общего грейда. Оценки относятся к отдельным карточкам, а не автоматически присваивают должность.

Решения задач раскрываются отдельно от условия и не попадают в копируемое задание. Если браузер запрещает доступ к буферу, появится текст для ручного копирования. Если локальное сохранение недоступно, сайт сообщит об этом и продолжит работу в памяти.

Копируемая задача содержит только заголовок, основное задание, точные условия, примеры и стартовый код. Граница одинакова при закрытом/открытом разборе и ручном копировании. Структура банка — 9 тем × 4 вкладки × 15 карточек; `id`, `topic`, `tab`, `ordinal`, `targetLevel` сохраняются для совместимости интервью. `verifiedAt` меняют только после технической сверки, а не при редактуре формулировки.

Проверки без зависимостей: `node --test tests/*.test.js` из корня репозитория. Браузерная проверка: `node tests/browser-check.cjs` с установленным вне проекта Playwright (путь в `PLAYWRIGHT_MODULE`) и Chromium/Edge (`BROWSER_PATH`, если браузер не установлен Playwright). Скрипт поднимает временный локальный сервер и проверяет все вкладки, ветки, копирование, сохранённые оценки, итоги и мобильную ширину.

Банк содержит вопросы по HTML, CSS, JavaScript, TypeScript, React, TanStack Query, Redux, архитектуре/FSD и практические задачи. React, Redux и TypeScript здесь — темы интервью; в реализации сайта они не используются.
